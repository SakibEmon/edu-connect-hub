# Edu Connect Hub

**Edu Connect Hub** is a lightweight, role-based Learning Management and Academic Administration System built with PHP and MySQL. Designed to streamline academic workflows, it enables smooth collaboration between administrators, instructors, and students for coursework, assessments, and attendance management.

---

## 🚀 Key Features

### 👨‍🏫 Instructor / Teacher Panel
- **Quiz Management:** Create, configure, and assign chapter- or topic-based quizzes with structured question sets.
- **Course Material Sharing:** Upload lecture notes, PowerPoint presentations (PPT/PPTX), and share video lecture links.
- **Attendance Tracking:** Record and monitor daily student attendance by class and subject.
- **Result Analytics:** Track quiz participation, review submissions, and analyze class performance.

### 🧑‍🎓 Student Portal
- **Interactive Assessments:** Attempt assigned quizzes online with immediate result feedback.
- **Learning Resources:** Access and download lecture slides, reference documents, and watch class videos.
- **Academic Progress:** View attendance records and overall performance summaries.

### 🛠️ Administrator Panel
- Centralized user enrollment management (teachers and students).
- Overall system oversight and academic data monitoring.

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript (React JS)
- **Backend:** PHP
- **Database:** MySQL
- **Environment:** Apache HTTP Server
